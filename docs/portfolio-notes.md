# Campus Mate 作品集展示说明

## 一句话介绍

Campus Mate 是一个面向大学生的校园互助社交平台，支持竞赛组队、吃饭搭子、兴趣搭子、用户认证、个人中心和收藏管理。

## 作品集展示角度

### 1. 产品场景

项目聚焦大学生真实需求：找竞赛队友、约饭、找运动或学习伙伴。相比单纯的练习项目，它有明确的用户场景和业务边界。

### 2. 全栈能力

项目包含前端页面、后端 API、数据库设计、登录认证和部署配置，可以展示完整 Web 应用开发能力。

### 3. 后端设计

可以重点说明以下能力：

- Express 路由拆分
- SQLite 表结构设计
- JWT 登录认证
- bcrypt 密码加密
- 发布者权限校验
- Railway 部署适配

### 4. 可继续扩展

后续可以继续扩展评论、私信、举报审核、分页搜索、PostgreSQL 数据库和自动化测试，让它从课程项目升级为更完整的产品原型。

## GitHub 展示建议

1. 仓库首页 README 保持截图、功能、运行方式、部署方式齐全。
